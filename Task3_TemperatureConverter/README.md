## Description

A professional temperature converter web application that allows users to convert between Celsius, Fahrenheit, and Kelvin. Built with HTML, CSS, and JavaScript with a clean white background design.

## Features

### Core Features
- Convert between Celsius, Fahrenheit, and Kelvin
- Input validation with error messages
- Dropdown menus for unit selection
- Clean professional white background design
- Responsive for all devices

### Bonus Features
- Dark Mode and Light Mode Toggle
- Conversion History (saves last 10 conversions)
- Reset Button
- Live conversion formulas display
- Animated result display
- Local storage persistence for history and theme preference

## Conversions Supported

| From | To | Formula |
|------|-----|---------|
| Celsius | Fahrenheit | (°C × 9/5) + 32 = °F |
| Celsius | Kelvin | °C + 273.15 = K |
| Fahrenheit | Celsius | (°F - 32) × 5/9 = °C |
| Fahrenheit | Kelvin | (°F - 32) × 5/9 + 273.15 = K |
| Kelvin | Celsius | K - 273.15 = °C |
| Kelvin | Fahrenheit | (K - 273.15) × 9/5 + 32 = °F |

## Technologies Used

- HTML5 - Semantic structure
- CSS3 - Styling, Flexbox, animations, dark mode
- JavaScript (Vanilla) - Conversion logic, validation, local storage
- Google Fonts (Inter) - Modern typography
