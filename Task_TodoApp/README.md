# TaskFlow - To-Do Web Application

## Oasis Infobyte Internship - Level 2 Task 3

## Live Demo

View Live Demo: https://SamkeloMazeka27.github.io/OIBSIP/Task_TodoApp/

## Features

### Core Features
- Add new tasks with timestamp
- View pending tasks list
- Mark tasks as complete
- View completed tasks list
- Edit existing tasks
- Delete tasks
- Persistent storage (local storage)

### Additional Features
- Task statistics (total, pending, completed)
- Creation date and time for each task
- Completion date and time tracking
- Responsive design for all devices
- Clean modern UI
- Keyboard support (Enter to add)

## Technologies Used
- HTML5
- CSS3 (Flexbox, Grid)
- JavaScript (Vanilla)
- Local Storage API
