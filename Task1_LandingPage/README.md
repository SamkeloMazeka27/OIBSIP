# VPN Landing Page

## Oasis Infobyte Internship - Task 1

## Live Demo

View Live Demo: https://SamkeloMazeka27.github.io/OIBSIP/Task1_LandingPage/

## Description

A modern, fully responsive VPN service landing page built with HTML and CSS only. This page showcases a professional VPN service with all essential sections including header, hero, features, device compatibility, statistics, and footer.

## Features

### Header Section
- Sticky navigation bar with logo
- Navigation menu (Home, Features, Pricing, Contact)
- Call-to-action "Sign In" button
- Hover effects on all links

### Hero Section
- Large, attention-grabbing heading
- Compelling description text
- Get Started button with hover animation
- CSS shape illustrations (no external images)

### Features Section (3 Core Features)
- Stronger Data Protection - Military-grade encryption
- Works Seamlessly Everywhere - Global content access
- Lightning-Quick Connectivity - Ultra-fast servers
- Card hover effects with lift animation

### Devices Section
- Supported devices: Phone, Tablet, Laptop, Desktop
- Emoji-based device icons
- Hover scale effects
- Note about unlimited simultaneous connections

### Statistics Section
- 1.2M+ Happy Users
- 94 Countries Served
- 3,200+ Secure Locations
- Gradient background with hover effects

### Footer Section
- Social media links
- Copyright information
- Complete contact details (email, phone, address)
- Quick links to product, company, and support pages

## Technologies Used

- HTML5 - Semantic structure
- CSS3 - Styling, Flexbox, Grid, animations
- Responsive Design - Mobile-first approach
- Google Fonts (Inter) - Modern typography
