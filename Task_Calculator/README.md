## Live Demo

View Live Demo: https://SamkeloMazeka27.github.io/Task_Calculator/

## Description

A fully functional calculator web application built with HTML, CSS, and JavaScript. This calculator performs basic mathematical operations including addition, subtraction, multiplication, and division. It also includes advanced features like percentage calculations, sign toggling, parentheses for complex expressions, and an ANS button to reuse previous results.

## Features

### Basic Functions
- Addition (+)
- Subtraction (-)
- Multiplication (×)
- Division (÷)
- Percentage (%)
- Sign toggle (±)
- Decimal point (.)

### Advanced Features
- Parentheses ( ) for complex expressions
- ANS button to use last calculated result
- Clear (C) to clear current entry
- Delete (DEL) to remove last character
- All Clear (AC) to reset everything
- Real-time expression evaluation
- Error handling for invalid operations

### User Interface
- Clean dark theme design
- Responsive grid button layout
- Hover effects on all buttons
- Active state feedback
- Mobile responsive design
- Large display screen for expressions and results

### Keyboard Support
- Number keys (0-9)
- Operator keys (+, -, *, /)
- Enter key for equals
- Backspace key for delete
- Escape key for clear
- Period key for decimal
- Percent key for percentage
- Parentheses keys ( and )

## Technologies Used

- HTML5 - Structure and layout
- CSS3 - Styling, grid system, animations
- JavaScript (Vanilla) - Calculator logic, event handling, keyboard support
